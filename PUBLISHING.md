# Publishing a New Nexus Prima Journal Article

The Journal is hosted independently at `journal.nexusprima.org`.

1. Copy `_publishing/article-template/` to a new root folder, for example `adjacent-possible/`.
2. Rename and edit its `index.html`.
3. Add the article cover image inside that new folder.
4. Add a publication card to the root `index.html`.
5. Add the article URL to `sitemap.xml`.
6. Keep the main Nexus Prima website separate.

Example final URL:

`https://journal.nexusprima.org/adjacent-possible/`
