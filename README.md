# Nexus Prima Journal — Subdomain Website

Deployment-ready build for `https://journal.nexusprima.org`.

- `/` is the permanent Journal library.
- `/mars-city/` is **Mars City — Article 001, Version 1.0**.
- `/_publishing/` contains the reusable workflow and article template.
- The Nexus Prima logo and navigation return readers to `https://nexusprima.org`.

Deploy the **contents of this folder** to the root of a separate repository or hosting project. Do not upload the enclosing folder itself. Configure that project’s custom domain as `journal.nexusprima.org`.
